##MoD Annual Report Analysis: FY 2023-24 vs 2024-25 Dashboard

A Power BI Report that breaks down India's Ministry of Defence Annual Report into an interactive, year-over-year comaprison - covering budget allocation, defence production, exports, gallantry awards, HADR operations, and welfare schemes.

Short Description /  Purpose

The MoD Annual Report Analysis Dashboard is an interactive Power BI report built to help users explore and compare Ministry of Defence performance across FY 2023-24 and FY 2024-25. It consolidates data spread across a lengthy government annual report into a single, filterable view. This tool is intented for policy analysts, defence researchers, and anyone who wants a faster way to track year-on-year change in India's defence sector than reading a 200+ page PDF.

Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop - Main data visualization platform used for report creation.

📂 Power Query - Data cleaning and transformation for reshaping the annual report data.

🧠 DAX (Data Analysis Expression) - Used for calculating measures, and creating a metric slicer.

📝 Data Modeling - Established relationships across multiple tables to enable cross-filtering and aggregation.

📂 File Format - .pbix for development and .png for dashboard previews.

Data Source

Source: Ministry of Defence (Government of India) Annual Report, FY 2023-24 and FY 20224-25 editions.
https://mod.gov.in/en/annual-report

Features / Highlights

Business Problem:

The MoD Annual Report is a dense, text-heavy government publication, making it difficult to quickly answer questions like:
1) Which service recieved the largest budget increase between FY24 and FY25?
2) Is the private sector's share of defence production growing?
3) How many HADR operations were conducted each year, and where?
4) How are welfare schemes and CSR contributions trending?
These are hard to answer quickly from the raw report.

Goal of the Dashboard:

To deliver an interactive visual tool that:

1) Enables users to compare MoD performance across FY 2023-24 and FY 2024-25.
2) Supports quick analysis of budget, exports, productions, and welfare trends.
3) Surfaces major HADR operations and Honoury Awards in acessible, visual format.

Walkthrough of Key Visuals

Budget & Honours Overview (Page 1)

A clustered column chart comapring FY24 RE vs FY25 RE budget by Service/Department, KPI cards for % increase/decrease in budget allocation of Navy and Airforce. A clustered column chart of defence export value (in crore) by year, a KPI card for % increase in defence exports. A donut chart of Gallantry and Distinguished Awards by Occassion, and a metric Slicer to filter the Awards accroding to Year and Category.

Defence Production Trends (Page 2)

A line chart comparing quarterly production value (in crores) across DPSUs, New DPSUs (erstwhile OFB), Non-DPSUs, and Private Companies, with a callout noting that Private-sector contribution is growing faster thatn DPSUs, narrowing the gap with New DPSUs.

HADR Operations (Page 3)

KPI cards showing total HADR operations in 2023-24 vs 2024-25, alongside a visual timeline of major operations each year - including the Silkyara Tunnel rescue, Operation Dost, Wayanad Landslide (2024-25) and many more.
Welfare & Grants (Page 4)

A table of beneficiaries by ex-servicemen welfare scheme. An area chart of CSR contribution (in crore) by financial year, representing the % increase in CSR contribution as well. A clustered column chart comparing 2023-24 vs 2024-25 revised estimates by grant category.

Other Key Statistics (Page 5)

Matrix Tables comapring the Budget Statistics, ICG operationa and programmes,and ECHS Statistices for the year 2023-24 and 2024-25. An area chart depicting BRO's budget expenditure along with % increase in budget expenditure of year 2024-25. A clustered column chart of NCC Units by year and a KPI card of cadet strength to be increased from 2024-25 in the next 3 years.
